Odoo Square Integration

Square POS orders, refunds, exchanges, and inventory sync for Odoo 17

Webhook Processing

Process Square order, payment, and refund webhooks through a dedicated Odoo controller with HMAC-SHA256 signature validation when a webhook signature key is configured.

Sales and Accounting

Create and update Odoo sale orders, invoices, credit notes, and refund records while preserving the Square order identifiers needed for traceability.

Inventory Mapping

Map Square locations to Odoo warehouses so stock movements and inventory adjustments stay tied to the correct operational location.

Operational Visibility

Use integration logs, webhook queue records, and manual resync tools to monitor and recover Square synchronization workflows.
