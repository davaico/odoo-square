# Square brand asset

`odoo_square/static/description/icon.png` is the unmodified black Square symbol
PNG (300 x 300) from Square's official brand resources, downloaded on 2026-11-16.
The same local file is used for the addon icon and the HTML description header.

- Source and usage guidelines: https://design.block.xyz/square/guidelines/logo
- Official download: https://design.block.xyz/downloads/square_symbol.zip
- Archive entry: `square_symbol/square_symbol_black.png`
- SHA-256: `f80437818552ffbf04c603bdab40fdd128ad9abb4eda2ea83377bfdd68da250d`

Square identifies the symbol as suitable for compact placements such as app icons.
The description header preserves its proportions and black color and leaves 40 px
of clear space around it. It labels this addon as an independent Davai integration.
