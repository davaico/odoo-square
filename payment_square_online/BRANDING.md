# Square Online Payments listing assets

The two release branches use the same visual design and assets, with installation
instructions specific to their Odoo version. Images are stored locally; the Store
description does not load images or scripts from third-party hosts.

## Official Square symbols

- Source: https://design.block.xyz/square/guidelines/logo
- Download: https://design.block.xyz/downloads/square_symbol.zip
- `icon.png`: unmodified black Square symbol, 300 x 300.
- `square-symbol-white.png`: unmodified white Square symbol, 300 x 300.
- Reused from the repository's existing `odoo_square/static/description/` assets.

## Online card-payment illustration

- File: `square-online-payments.png`, 2400 x 1260, preserved unmodified.
- Source page: https://developer.squareup.com/us/en/online-payment-apis
- Asset: https://images.ctfassets.net/2d5q1td6cyxq/10yvCZFI7wkAaCwsCAGAiQ/98c9490f8f9d6eb6a0ad9abf0b823a05/PD00612_-_developers_online_payments_social.png
- Used as the manifest cover and in the HTML description.

This is Square's online card-payment illustration, not a screenshot of the Odoo
addon. The visible caption identifies it accordingly. No terminal, wallet-button
or recurring-payment imagery is used to represent this card-checkout addon.

Square assets remain property of their owner. The addon license does not grant
rights to Square trademarks or artwork.
